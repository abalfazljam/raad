# Raad Browser Extension (کروم + فایرفاکس)

| پوشه | مرورگر | نسخه مانیفست |
|---|---|---|
| `chrome/` | Chrome / Edge / Brave / Opera | MV3 (service worker) |
| `firefox/` | Firefox 102+ | MV2 (event page) |

> دو پوشه از **یک سورس مشترک** ساخته شده‌اند؛ `bg.js`، `content.js`، `popup.html` و `popup.js` در هر دو یکسان‌اند.

## نصب سریع
- **کروم:** `chrome://extensions` → Developer mode → **Load unpacked** → همین پوشه `chrome`
- **فایرفاکس:** `about:debugging#/runtime/this-firefox` → **Load Temporary Add-on** → `firefox/manifest.json`
- برای انتشار دائمی فایرفاکس: محتویات پوشه `firefox` را zip کن و در AMO آپلود کن

## اتصال (نسخه 1.6 — خودکار)
1. فقط برنامه رعد را اجرا کن — تمام!
2. افزونه خودش پورت‌های `27500…27520` را اسکن می‌کند، برنامه را با `/ping` پیدا می‌کند و با `/pair` پورت و توکن را خودکار ذخیره می‌کند.
3. اگر متصل نشد: آیکون افزونه → دکمه `↻` (اتصال مجدد). کادر JSON فقط برای عیب‌یابی دستی است.

## رفتار (به‌روزِ نسخه 1.3 افزونه)
- **هر دانلودی که در مرورگر شروع شود** → اگر رعد در حال اجرا باشد، اول به رعد ارسال می‌شود و **بعد از پذیرش**، دانلود مرورگر لغو می‌شود (در 1.6 اول لغو می‌شد — اگر ارسال شکست می‌خورد دانلود از دست می‌رفت). اگر رعد اجرا نباشد یا نپذیرد، دانلود عادی مرورگر ادامه می‌یابد.
- دانلود به‌صورت **خودکار و فوری** در رعد شروع می‌شود + پنجره پیشرفت باز می‌شود؛ بعد از پایان، کارت «کامل شد» با اجرا/پوشه/کپی/درگ می‌آید (قابل تغییر از تنظیمات برنامه).
- **کوکی‌ها پیش‌فرض روشن‌اند** (سشن لاگین مرورگر همراه دانلود می‌رود؛ مثل IDM) — از پاپ‌آپ قابل خاموش‌کردن است.
- **رابط فارسی‌محور:** پاپ‌آپ و منوی راست‌کلیک پیش‌فرض فارسی‌اند؛ دکمه EN در پاپ‌آپ زبان را عوض و به‌خاطر می‌سپارد.
- راست‌کلیک → **رعد → ⬇ دانلود با رعد**
- در popup افزونه: خاموش/روشن کردن interception، ارسال کوکی (خوانده‌شده از `chrome.cookies` — دقیق‌تر از `document.cookie`)، اعلان‌ها، غیرفعال‌سازی برای سایت خاص
- نشان آیکون: سبز `✓` متصل، `!` برنامه پیدا نشد، `OFF` شنود خاموش
- اگر در برنامه توکن عوض شود، افزونه خودش دوباره جفت‌سازی می‌کند (self-heal)
